# Pedido por Voz

App para tiendas de accesorios y ferretería: dictas el pedido por voz y obtienes la proforma con los precios del inventario. Incluye clientes, promociones por WhatsApp, caja y resumen de ventas.

Se instala en Android desde Chrome (menú ⋮ → "Instalar app") y funciona sin internet. Los datos se guardan solo en el teléfono; usa ⚙ → "Descargar respaldo" con frecuencia.
